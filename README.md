# ことばの進捗帳

note記事制作の予定と進捗を管理する、日本語のシンプルなWebアプリです。外部API、ログイン、追加パッケージは使いません。

## 起動方法

1. このフォルダでターミナル（コマンドを入力する画面）を開きます。
2. 次のコマンドを入力してEnterを押します。Python 3が必要です。

   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

   Windowsでは `py -m http.server 8000 --bind 127.0.0.1` を使えます。
3. 自分のパソコンで実行した場合、ブラウザのアドレス欄に `http://127.0.0.1:8000` を入力します。
4. 終了するには、ターミナルでCtrl+Cを押します。

クラウド環境では `/workspace/my-one` が作業フォルダです。上のアドレスはサーバーを実行した端末専用です。この環境のセットアップ画面はWebプレビューに対応していないため、画面を操作するにはファイルを自分のパソコンにダウンロードして上の手順で実行してください。

## 使い方

- 「新しい記事」からクライアント名、記事タイトル、納期、制作ステータスを登録します。
- ステータスは「構成作成」「執筆中」「確認待ち」「納品済み」の4つです。「編集」で変更できます。
- 一覧は納期が近い順です。検索とステータスボタンで記事を絞り込めます。
- 未納品で納期を過ぎた記事には注意表示が出ます。納期当日は期限超過として扱いません。
- 「削除」は確認画面を経て記事を削除します。

## 保存について

データはブラウザのlocalStorageに保存します。ページを閉じても同じブラウザ・同じアドレスで開けば残ります。端末間の同期はありません。ブラウザのデータ削除やプライベートモードの終了で消える場合があります。大切な情報は別途控えてください。ポート番号やアクセスするアドレスを変えると別の保存場所になります。

## ファイル

- `index.html`: 画面
- `style.css`: パソコン・スマートフォン向けのデザイン
- `app.js`: 登録・編集・削除・検索・ブラウザ内保存

開発時も既存のフォルダを使います。依存パッケージのインストールやビルドは不要です。

## GitHub Pagesで公開する

アプリの公開には、GitHubのこのリポジトリで **Settings → Pages** を開き、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/(root)** にして **Save** を押します。公開が完了したら、Pages画面に表示されるサイトのリンクを開いてください。

公開されるのはアプリの画面とプログラムです。入力した記事情報は各利用者のブラウザ内だけに保存され、GitHubには送信されません。
